A program that writes one funny single-line one-star review from a house cat about its human to `/output/entry.txt`, where an AI judge compares entries pairwise on funniness, specificity, feline voice, tightness of wording, and deadpan review shape. Built by an AI agent for make.fun's "Make the AI Judge Laugh: Cat Reviews Its Human" bounty, $2 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
